🎮 スパ2X チーム管理＆OBSツール（テスト版）

📌 概要
スーパーストリートファイターII X（Super Street Fighter II Turbo）の16キャラ戦を管理するWebアプリです。
チーム分け・オーダー設定・キャラ選択ができ、OBSの配信画面にそのまま表示できます。

[ここにGitHub PagesのURLを貼る]

🚪 部屋の入り方

このアプリには2つのモードがあります。URLの末尾に `?room=◯◯` を付けるかどうかで切り替わります。

1. 通常モード（友達と使うとき）
```
https://xxxxx.github.io/xxxxx/
```
`?room=` を付けずにそのまま開くモードです。開いた人ごとにブラウザの中だけでデータが保存され、他の人の操作には一切影響しません。スマホから複数人が同時に開いても、お互いに干渉しないので安心して使えます。ページを閉じたりリロードしても、前回の状態は自動で復元されます。

2. 同期モード（複数端末から同じデータを操作したいとき）
```
https://xxxxx.github.io/xxxxx/?room=好きな部屋名
```
`?room=` の後ろに好きな部屋名を付けて開くモードです。PC・スマホなど複数端末から同じ `room名` のURLを開くと、リアルタイムでデータが同期されます（1台を操作すると他の端末にもすぐ反映されます）。

⚠️ 注意
- 部屋名はURLを知っていれば誰でも入れます。パスコードのような仕組みはないので、他人に推測されにくい部屋名（例: `ume-2026-0410` のような日付や文字列を混ぜたもの）を使うことをおすすめします。
- `default` のような単純な部屋名は避けてください。

📝 使い方
1. 管理操作パネルでその日の参加者にチェックを入れる
2. 「チェックした人を1P / 2Pチームに自動振り分け」ボタンを押す
3. 各チームの「オーダー設定」ボタンからキャラを選ぶ
4. OBSにはチーム表示部分をブラウザソースとして取り込む

🔄 リセット
状態を初期化したいときは、該当するセクションのリセット操作を行ってください。
